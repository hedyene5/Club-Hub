Erreur : "mvn n'est pas reconnu"

Solution :
1. Téléchargez Maven : https://maven.apache.org/download.cgi
2. Extrayez dans : C:\Program Files\Apache\maven
3. Ajoutez au PATH Windows :
   - Recherchez "Variables d'environnement"
   - Modifiez "Path"
   - Ajoutez : C:\Program Files\Apache\maven\bin
4. Redémarrez PowerShell
5. Vérifiez : mvn --version
