Erreur "mvn n'est pas reconnu" :
→ Maven n'est pas installé ou pas dans le PATH

Erreur "Port 8084 already in use" :
→ netstat -ano | findstr :8084
→ taskkill /PID <PID> /F

Erreur 404 sur /api/ai/... :
→ Le backend Spring Boot n'est pas démarré
→ Relancez l'ÉTAPE 2

Le bouton IA est grisé :
→ Remplissez d'abord "Parlez-nous de vous"
