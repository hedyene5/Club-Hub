📌 MÉTHODE 1: SCRIPT AUTOMATIQUE (Recommandé)
═══════════════════════════════════════════════════════════════════

1. Assurez-vous que MongoDB est démarré
2. Double-cliquez sur: start-all.bat
3. Attendez 30-60 secondes
4. Le navigateur s'ouvrira automatiquement sur http://localhost:4200

═══════════════════════════════════════════════════════════════════

📌 MÉTHODE 2: LANCEMENT MANUEL
═══════════════════════════════════════════════════════════════════

Ouvrez 4 terminaux:

Terminal 1 - Gateway (Port 8084):
  cd Club-Hub-Voice-Channel-Management/Gateway/Gateway
  ./mvnw spring-boot:run

Terminal 2 - User Service (Port 8081):
  cd Club-Hub-Voice-Channel-Management/User/ClubHub
  ./mvnw spring-boot:run

Terminal 3 - InstantVoice (Port 8082):
  cd Club-Hub-Voice-Channel-Management/Back/InstantVoiceManagment
  ./mvnw spring-boot:run

Terminal 4 - Frontend (Port 4200):
  cd Club-Hub-Voice-Channel-Management/User/Front
  npm start

═══════════════════════════════════════════════════════════════════

❌ PROBLÈMES COURANTS
═══════════════════════════════════════════════════════════════════

MongoDB pas démarré:
  net start MongoDB

Port déjà utilisé (ex: 8081):
  netstat -ano | findstr :8081
  taskkill /PID <PID> /F

Erreur "Cannot find module" (Frontend):
  cd User/Front
  npm install
